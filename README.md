# Summit

## Команда

- Владислав Скирда
- Михайло Рябченко

## Опис

У Summit мандрівники зможуть обрати гірський маршрут за складністю, тривалістю та зупинками. Деякі маршрути можуть не мати організатора чи пропозицій групових сходжень. Їхній опис можна буде використати для планування самостійного походу. Якщо на маршруті є організовані сходження, можна буде порівняти дати й ціни та перевірити наявність вільних місць.

## Основний функціонал

- Перегляд гір за країнами та маршрутів для обраної вершини.
- Перегляд зупинок, складності й тривалості маршруту.
- Перегляд пропозицій сходжень із датами, ціною та кількістю місць.
- Збереження цікавих пропозицій в обраному.
- Запис на конкретне сходження через Discord та оновлення кількості вільних місць.

## Ролі користувачів

- **Гість** зможе переглядати каталог, маршрути та пропозиції сходжень.
- **Учасник** зможе зберігати пропозиції в обраному й підтверджувати участь у сходженні через Discord.

У картці організованого сходження можна буде переглянути інформацію про організатора(якщо організатор буде).

## Особливість проєкту

Плануємо додати запис через Discord-бота. Посилання зі сторінки сходження відкриватиме повідомлення про цю подію на сервері Summit. Якщо учасник натисне «Так», бот перевірить наявність місця й підтвердить запис. Кількість вільних місць на сайті зменшиться на одне. Повторне підтвердження тією самою людиною не займатиме ще одного місця. Кнопка «Ні» завершить діалог. Якщо групу вже набрано, бот відповість «Місць немає».
